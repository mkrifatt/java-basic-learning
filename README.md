# Java Basic Learning — Ordered Practice

This repository keeps the original practice code and comments, but organizes the lessons in the order they should be understood.

## Learning order

1. `step01_basics` — variables, conditions, loops, arrays, ArrayList
2. `step02_classes_and_objects` — class blueprint, fields, creating objects
3. `step03_constructors` — constructors and `this`
4. `step04_methods` — creating and calling methods
5. `step05_methods_calculations` — methods that calculate and return values
6. `step06_encapsulation` — private fields and controlled access
7. `step07_getters_and_setters` — getters, setters, and validation

### Important
Your original comments and learning notes are intentionally preserved. Package declarations were changed only so the new folders work correctly in Eclipse.
